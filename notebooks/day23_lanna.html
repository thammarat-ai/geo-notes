Day 23 · Senses: Taste — อาหารเหนือในแผนที่ไทย

#30DayMapChallenge 2026 · 23 พ.ย. 2569 · โจทย์: “Food, drink or something else which you can taste.” ธีมพิเศษที่อาจารย์ขอ: อาหารภาคเหนือ (ลาบ · ข้าวซอย)

ทำไมต้องวัดแบบนี้

OSM มีแท็กบอกประเภทอาหารคือ cuisine แต่ในไทยมันถูกใช้เป็นคำรวม: ค่าที่ใช้จริง 665 ค่า รวม 25,388 ครั้ง มี thai, coffee_shop, burger, pizza, chicken เป็นหลัก ส่วนคำที่เอ่ยถึงอาหารเมือง (ข้าวซอย, ลาบ, northern_thai) รวมกันได้ 9 ครั้ง ขณะที่คำว่า “อีสาน” ใน cuisine ถูกใช้ 28 ครั้ง — และแท็ก diet (เจ/มังสวิรัติ/ฮาลาล) ไม่ถูกใช้เลย (0 ค่า)

แปลว่า รส ไม่ได้อยู่ในหมวดหมู่ของแผนที่นี้ สิ่งที่ OSM บันทึกไว้จริงคือ ป้ายชื่อร้าน คน map ท้องที่พิมพ์ name ตามที่เห็นหน้าร้าน (“ข้าวซอยต้นข่อย”, “ไส้อั่วป้าตุ๋ย”, “ลาบไก่บ้านโอ่ง”) โน้ตบุ๊กนี้จึงอ่าน “รส” จาก name ของ object ทั้งประเทศที่สแกนจาก Geofabrik Thailand extract (md5 db3958a037ce717c462101b86e2f75f3) เหมือน Day 21–22

นิยามที่ใช้

สิ่ง นิยามในโค้ด
object อาหาร amenity ในหมวดอาหาร/เครื่องดื่ม, หรือ shop ในหมวดของกิน, หรือมีแท็ก cuisine (ทั้งประเทศ 59,703 ชิ้น = node 51,062 + way 8,641)
คำที่ค้นหา 11 คำ Lanna (ข้าวซอย ไส้อั่ว น้ำพริกหนุ่ม น้ำพริกอ่อง แคบหมู ฮังเล น้ำเงี้ยว แกงแค ตำขนุน แอ็บ จิ้นส้ม) + 2 คำควบคุม (ลาบ, หน่อไม้)
การ match NFKC + ตัดช่อง + substring ใน name / name:en / alt_name / official_name / sig / sign / brand
กรอง false positive เฉพาะคำว่า “ลาบ” ห้ามตัวหน้าเป็น ห ส ะ า ำ ป พ เ ู (กัน กุหลาบ, แม่สลาบ, สะลาบ, ปลาบึก, ศาลาบู, เลาบราเดอร์ส, พลาบูรพา)
จังหวัด representative point + STRtree.query(..., predicate="within") บน Natural Earth admin_1
ระยะ จากจุดทะเบียนถึง ขอบวัตถุ ใน Equidistant Conic เดียวกับทั้งซีรีส์ (Day 22 วัดว่า projection นี้คลาดพื้นที่ −0.3617%) ตามหาในรัศมี 40 กม.

บั๊ก 4 ตัวที่เจอระหว่างทำ (โน้ตบุ๊กนี้บันทึกไว้ทั้งหมดใน day23_stats.json)

  1. ลาบ ชนกับคำว่าไม่เกี่ยว — รอบแรกได้ 304 ร้าน รวม บ้านแม่สะลาบ, แม่สลาบ, กุหลาบพันปี, เลาบราเดอร์ส, ถนนพลาบูรพาพัฒน์ → ใส่ negative lookbehind เหลือ 155 คู่
  2. การกรองทำให้ recall หาย — ตอนแรก re-check เฉพาะช่อง name จึงเผลอตัดร้านที่ สแกนเจอผ่าน alt_name ทิ้ง (เช่น BBQ Mae Sariang) → แก้ให้สแกนเก็บ “สตริงที่ใช้ค้นหา” ลงไฟล์แล้วตรวจซ้ำบน string เดียวกัน
  3. argmin บน array ที่กรองแล้ว ≠ index ของตาราง — ทำให้ ชื่อร้านที่ใกล้ที่สุด สลับกับร้านคนละแห่ง (ระยะทางถูก แต่ป้ายชื่อผิด)
  4. STRtree.query(pt, predicate="contains") คืนค่าว่าง สำหรับ “จุดในโพลิกอน” บน shapely 2.x — ต้องใช้ predicate="within" (บทเรียนเดียวกับ Day 21)

def _clean(o):
    """NaN/Inf ออกมาเป็น null (json ที่ allow_nan=False ไม่ยอมให้มี NaN และเบราว์เซอร์อ่านไม่ออก)"""
    if isinstance(o, dict):
        return {k: _clean(v) for k, v in o.items()}
    if isinstance(o, (list, tuple)):
        return [_clean(v) for v in o]
    if isinstance(o, (float, np.floating)):
        f = float(o)
        return None if (math.isnan(f) or math.isinf(f)) else f
    if isinstance(o, (bool, np.bool_)):
        return bool(o)
    if isinstance(o, (int, np.integer)):
        return int(o)
    return o
