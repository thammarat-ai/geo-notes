When does something become a map and when does it stop being one?” (หัวข้อ Is this a map? — ดึงข้อความมาจากหน้า 30daymapchallenge.com อ่านสดวันที่ 26 พ.ย. และเก็บสำเนาไว้ที่ scratch/chal25.html)

โจทย์ไม่ได้ขอแค่ “ทำให้สวย” แต่ขอ เส้นแบ่ง ผมจึงไม่อยากตอบด้วยปรัชญา คำตอบของโพสต์นี้ เป็นตัวเลขที่วัดได้ และคำถามที่ผมใช้แทนโจทย์คือ:

ถ้าเอาข้อมูลเดิมมาแสดงเป็นสามแบบ — แผนที่ / โครงสร้างล้วน / ภาพวาด — แบบไหนยัง “ชี้ที่เดียวกัน” ได้ และแบบไหนเลิกเป็นแผนที่ตั้งแต่เมื่อไหร่

๐. ข้อมูล: กราฟถนน 82 จุด ในไฟล์เดียว 4.43 MB

Day 24 สแกน Geofabrik Thailand extract (md5 db3958a0…) แล้วเก็บกราฟถนนในจาน 5,000 ม. รอบจุดทะเบียน 83 แห่งไว้ในแคชของเครื่อง — ปัญหาของวันนั้นคือ ไฟล์แคชไม่ได้อยู่ในรีโป คนที่กดปุ่ม Colab จึงรันต่อไม่ได้ถ้าไม่มี PBF 330 MB

วันนี้ผม export มันออกมาเป็นไฟล์เดียว: data/day25_graphs.npz ขนาด 4.43 MB (tools/collect_day25_export.py) เก็บ 413,758 node-slot และ 430,464 บันทึกขอบ ซึ่งยุบเป็น 430,457 เส้นไม่ซ้ำ (มีคู่โหนดเดิมซ้ำกัน 7 บันทึกทั้งประเทศ) ครอบคลุม 82 จุด จุดที่ไม่มีถนนใน 5 กม. เลยคือ อุทยานแห่งชาติเขาใหญ่ เช่นเดียวกับ Day 21/24

ผู้ตัดสินคนแรกของโพสต์นี้คือ ตัวเลขต้องกลับมาเหมือนเดิม: สร้างกราฟจาก npz ใหม่ แล้วเทียบกับ day24_roads.csv ทุก 82 จุด ใน 7 คอลัมน์ (nodes / edges / components / bridges / deadend_ratio / avg_deg / access_dist_m) ผลต่างสูงสุด = 0 ทุกคอลัมน์ และได้ components เฉลี่ย 8.67 · bridges รวม 157,625 · dead-end มัธยฐาน 4.66% ตรงกับ Day 24

๑. สามสื่อของสถานที่เดียวกัน

ทุกจุดถูกตัดเหลือ “หน้าต่างร่วม” 1,000 โหนดแรกที่เดินถึงจากจุดเข้าถึง (เพื่อให้จุด 895 โหนด กับจุด 31,150 โหนดเทียบกันได้) แล้วสร้างสามสื่อจากโหนดชุดเดียวกัน

สื่อ สิ่งที่ดู หน่วย
map พิกัดจริงของโหนด (เมตรในระบบ projection ของซีรีส์) มีหน่วยวัดระยะ
hop เดินจากจุดหนึ่งไปอีจุดหนึ่งกี่ก้าว ไร้หน่วย
draw วาดใหม่จากความเชื่อมโยงอย่างเดียว (spring layout) แล้วทาบไม้บรรทัดบนรูป ไร้หน่วย
tag ป้ายหมายเลขสุ่มที่ไม่ได้มาจากข้อมูลเชิงพื้นที่เลย ระบุตัวตนได้ 100% แต่ไร้ความหมายเชิงที่ทาง

ลายเซ็นที่ใช้จับคู่คือ โปรไฟล์การเติบโต: สัดส่วนโหนดที่อยู่ภายในรัศมี 12 ระดับ โดยรัศมี normalize ด้วย P95 ของตัวมันเอง จึงไร้หน่วยและเทียบข้ามสื่อได้ ทำสองแบบ — radial1 (จุดเริ่มต้นเดียว = จุดเข้าถึง) กับ radial5 (ห้าจุดเริ่มต้นต่อสถานที่)

กติกาที่ตั้งไว้ ก่อนรัน: ผู้สมัคร k=1 · แต้มที่เท่ากันแตกด้วยเลขสุ่ม · ถือว่า “ยังจับคู่ได้” เมื่อ p < 0.05 และแม่นกว่าการสุ่มอย่างน้อย 3 เท่า · seed = 25 ทุกจุด

๒. ผลหลัก: เมทริกซ์จับคู่ข้ามสื่อ

chance ของฐาน “ทุกจุด” คือ 1/82 = 1.22% (ตารางเต็มมีทุกคู่ทุกฐานใน day25_ladder.csv)

ถาม → ตอบ ลายเซ็นจุดเดียว ลายเซ็นห้าจุด ผ่านเกณฑ์?
hop → map 1.22% (1 เท่า) 14.63% (12 เท่า) ✅ p = 0.00005, CI 7.32–23.17%
map → hop 1.22% (1 เท่า) 13.41% (11 เท่า) ✅ p = 0.00005
draw → map 0.00% 3.66% (3 เท่า) ❌ p = 0.081
draw → hop 1.22% 3.66% (3 เท่า) ❌ p = 0.078
tag → map 1.22% 1.22% (1 เท่า) ❌ (ตามที่ควรเป็น)
สลับหอภาพ (control) – 1.22% = chance พอดี ✅ ไม่มีสัญญาณปลอม

สามอย่างที่สำคัญในตารางนี้

หนึ่ง ลายเซ็นจุดเดียวแทบไม่มีพลัง (ทุกคู่ตกไปอยู่ที่ chance) การถามว่า “จากจุดเข้าถึง โตขึ้นเร็วแค่ไหน” เป็นคำถามที่ทุกจานถนน 5 กม. ในไทยตอบคล้ายกันหมด ต้องถามจากห้าจุด จึงเริ่มแยกที่ออก — นี่เป็นบทเรียนเรื่อง การออกแบบลายเซ็น ไม่ใช่เรื่องข้อมูล

สอง โครงสร้างล้วนยังจับคู่กับแผนที่ได้ 14.63%แม่นกว่าสุ่ม 12 เท่า และ ผ่านทั้งสามฐานผู้สมัคร: ฐาน “ขนาดใกล้เคียงกัน” (ผู้สมัครมัธยฐาน 13 จุด, chance 10.22%) ได้ 34.21% = 3.35 เท่า ฐาน “คนละภาค” (ผู้สมัครมัธยฐาน 60 จุด) ได้ 14.63% = 8.29 เท่า แปลว่าไม่ใช่เพราะ “จุดใหญ่หน้าตาเหมือนกัน” และไม่ใช่เพราะ “ถนนภาคเดียวกันคล้ายกัน”

สาม ภาพวาดจับคู่กับแผนที่ไม่ผ่านเกณฑ์ 3.66% คิดเป็น 3 เท่าของ chance ซึ่ง พอดี กับเกณฑ์ แต่ p = 0.081 ซึ่งไม่ต่ำกว่า 0.05 ที่ตั้งไว้ และในฐานคนละภาคได้ 4.88% (2.76 เท่า, p = 0.057) กล่าวคือ เมื่อคุณลบเมตรทิ้งแล้วเหลือแค่ “รูปที่วาดให้สวย” ข้อมูลที่จับคู่กลับไปยังแผนที่ แทบไม่เหลือ — นี่คือเส้นแบ่งที่ผมตามหา

และ ป้ายหมายเลข คือเครื่องเตือนใจ: มันระบุสถานที่ได้ 100% ในระบบของมันเอง แต่จับคู่กับแผนที่ได้แค่ chance ตรง ๆ การ “ชี้ได้” จึงไม่ใช่ความเป็นแผนที่ — ความเป็นแผนที่อยู่ที่ว่า ระยะทางยังแปลว่าระยะทางไหม ซึ่งคือตอนถัดไป

คำตอบของโจทย์วันนี้จึงไม่ใช่เส้นแบ่งที่ความสวยงาม แต่เป็นเส้นแบ่งที่ หน่วยวัด: ตราบใดที่ระยะทางระหว่างสองสิ่งยังเรียงตามจริงได้ สิ่งนั้นยัง “ทำหน้าที่อย่างแผนที่” พอคุณเหลือแค่ “รูปแบบ” ที่วัดไม่ได้ มันคือภาพวาด — สวยได้ แต่ไม่ใช่แผนที่

๔. งานศิลป์: ลายนิ้วมือ 82 แผ่น

แผ่นภาพด้านขวาของ day25_gallery.png คือภาพวาดจากความเชื่อมโยงอย่างเดียวของทั้ง 82 จุด วางไว้บนตำแหน่งจริงโดยไม่มี basemap ไม่มีสเกล ไม่มีคำอธิบาย สี = log จำนวนโหนดถนน (คือ “OSM รู้จักที่นี่มากแค่ไหน” จาก Day 16/21)

การจัดวางแบบแรก (ตามตำแหน่งจริง) ให้ Moran I = 0.2579, p = 0.0033 จากการสลับที่ 300 ครั้ง แปลว่า “สถานที่ที่ใกล้กัน มีปริมาณข้อมูลใกล้เคียงกัน” ยังอ่านออกจากรูป ส่วนแบบที่สอง (สลับช่องแบบสุ่ม) ทำลายข้อมูลเชิงพื้นที่นั้นทิ้ง — ภาพชุดเดียวกันกลายเป็นงานภาพนามธรรมล้วน ๆ นี่คือ “artwork” ที่โจทย์ขอ และเป็นหลักฐานว่าสิ่งที่ทำให้มันยังเป็นแผนที่คือ ตำแหน่งของแผ่นภาพ ไม่ใช่ตัวแผ่นภาพ

๕. สิ่งที่ผมเปลี่ยนกลางทาง (และทำไม)

โพสต์นี้เปลี่ยนวิธีทดสอบถึงสามรอบระหว่างทาง ผมคิดว่าควรบันทึกไว้เพราะทุกครั้งที่เปลี่ยน เป็นเพราะตัวเลขบอก ไม่ใช่เพราะรู้สึก

หนึ่ง leave-one-out ใช้ไม่ได้โดยนิยาม แผนเดิมคือ “กันตัวเองออกจากหอภาพแล้วให้ทาย” แต่ถ้าหนึ่งสถานที่มีภาพเดียว การกันตัวเองออกจากการแข่งขันทำให้คำตอบที่ถูกไม่มีอยู่ในรายการ ผลคือความแม่นเป็น 0 โดยไม่เกี่ยวกับข้อมูลเลย → เปลี่ยนเป็น split-half (แบ่งข้อมูลเป็นสองซีก)

สอง split-half ก็ใช้ไม่ได้กับเครือข่ายเชิงพื้นที่ ผมลองสามแบบแล้ววัดจริง (ค่าอยู่ใน discarded_design ของ stats): สุ่มรายขอบเหลือชิ้นที่เดินถึงมัธยฐาน 4 โหนด แบ่งตามท่อนถนนเหลือ 3 โหนด (กราฟขาดเป็นผุยผงทั้งที่ขอบครึ่งหนึ่งยังอยู่) แบ่งด้วยเส้นผ่านศูนย์กลางได้ 909 โหนด แต่สองซีกอยู่ คนละพื้นที่ ของจาน จึงเทียบ “รูปทรง” กันไม่ได้ → เลิกใช้ แล้วเปลี่ยนคำถามเป็นสิ่งที่โจทย์ถามจริง คือ จับคู่ข้ามสื่อ ซึ่งข้อมูลชุดเดียวกันทั้งสามสื่อ (ไม่มีการแบ่งจึงไม่มี leakage)

สาม บั๊กสองตัวที่ตัวควบคุมจับได้ (ก) ผมคำนวณ flat index ผิดใน null simulation ทำให้ “การสุ่ม” ชนะเกณฑ์ทุกขั้น (p = 1.0 ทั้งคอลัมน์) — ตอนนี้มีการ assert ว่า ค่าเฉลี่ยของการสุ่มต้องตรงกับ chance เชิงวิเคราะห์ (< 0.005) ทุกครั้ง (ข) กติกา “เสมอ = แพ้” ที่ผมตั้งไว้ตอนแรก กดค่า chance ของขั้นที่ข้อมูลหยาบ (เช่นค่าคุณภาพท้องฟ้าที่ซ้ำกันทั้งประเทศ) จน negative control ดูชนะการสุ่มแบบปลอม ๆ → เปลี่ยนเป็นแตกเสมอด้วยเลขสุ่ม ซึ่งคงค่า chance = 1/จำนวนผู้สมัครไว้ได้จริง

สี่ ตัวควบคุมที่ทำงาน “สลับหอภาพ” (ให้คำตอบเป็นโปรไฟล์ของสถานที่อื่นแบบสุ่ม) ได้ 1.22% = chance พอดี และ “ป้ายหมายเลข” ได้ 1.22% เช่นกัน — ทั้งสองยืนยันว่าเมทริกซ์ในข้อ ๒ ไม่ได้มีสัญญาณปลอมซ่อนอยู่

ว่าด้วยคำศัพท์

  • ความเป็นแผนที่ — ผมใช้คำนี้เป็น nominalisation ธรรมดาของ map-ness ไม่มีศัพท์มาตรฐานไทย และผมไม่ได้อ้างทฤษฎีใด ๆ มันคือชื่อของ “สิ่งที่เราวัดในโพสต์นี้”
  • โปรไฟล์การเติบโต — คำที่ผมตั้งเองให้ cumulative distribution ของระยะทางจากจุดหนึ่ง (หรือจากห้าจุด) โดยหารด้วยรัศมีของตัวมันเองเพื่อให้ไร้หน่วย
  • spring layout — อัลกอริทึมวาดกราฟที่มองโหนดเป็นมวล ขอบเป็นสปริง แล้วจัดตำแหน่ง ให้สปริงตึงที่สุด ผลที่ได้ “ดูเป็นแผนที่” แต่ไม่มีหน่วยวัดใด ๆ
  • Procrustes-fit — การย้าย/หมุน/ขยายภาพหนึ่งให้ทับอีกภาพใกล้ที่สุด เพื่อวัดว่า “เหลือเศษเท่าไร”
  • Moran I — ค่าทางสถิติที่บอกว่าสิ่งที่อยู่ใกล้กันบนแผนที่ มีค่า (ที่นี่คือจำนวนโหนด) ใกล้เคียงกันไหม
  • spearman rho — สหสัมพันธ์แบบ “เรียงอันดับ” ไม่สนใจขนาดตัวเลข ใช้ดูว่าสองการวัด ให้ลำดับเดียวกันไหม

ข้อจำกัด

  • โปรไฟล์การเติบโตเป็นลายเซ็นที่ผมออกแบบเอง ผลที่ได้จึงเป็น ขอบเขตล่าง ของข้อมูลที่สื่อหนึ่งเก็บไว้ ไม่ใช่ค่าสูงสุดที่เป็นไปได้ (คนออกแบบลายเซ็นเก่งกว่านี้อาจได้มากกว่า)
  • draw ใช้ spring_layout ซึ่งไม่มีเหตุผลใดจะคงทิศทางหรือสัดส่วนจริง ตัวเลขที่ต่ำของมันคือ คำตอบของโจทย์ ไม่ใช่ข้อผิดพลาดของวิธี
  • ทุกสื่อคำนวณบนหน้าต่าง 1,000 โหนดแรกจากจุดเข้าถึง กราฟที่ใหญกว่านั้น (ใหญ่สุด 31,150 โหนด) จึงถูกตัดเหลือเฉพาะส่วนที่เดินถึง
  • จาน 5,000 ม. ตัดถนนที่ยื่นเข้ามา ทำให้ 2.8% ของโหนด (มัธยฐานต่อจุด) เดินไปไม่ถึง components ที่มากกว่า 1 บางส่วนจึงเป็นผลของกรอบการศึกษา ไม่ใช่ความขาดจริงของถนน
  • ตัวเลขทั้งหมดเป็น “ต่อจุดดูฟ้ามืด” (82 จุด) ไม่ใช่ต่อโหนดถนน และ snapshot เดียวกับ Day 21–24 (21 พ.ย. 2569) — ถนนที่เพิ่มหลังวันนั้นไม่มีอยู่ในนี้
